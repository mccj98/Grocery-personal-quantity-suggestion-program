# Grocery-personal-quantity-suggestion-program
Inspired by grocery shops sales ordering systems.
I created this program because I tended to forget to buy items during my weekly grocery shop or not buy enough of something. To use this program, I define a product and set a target quantity level within the CSV file, then I use the program to enter my current items quantities. My python program performs a simple operation and returns a suggested quantity to buy / replenish. A list is generated at the end which I use when I’m shopping to eliminate forgetfulness and indecision.
